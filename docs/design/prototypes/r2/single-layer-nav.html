本原型（R2 提案）R2

MeCollageHomeBlogAboutTools ▾ · 5GitHub · 语言
  • 一层 64px：主导航 + 工具下拉 + 语言；移动 56px（复用 R1）。
  • 一个工具入口：5 个工具进 Tools 下拉，工具页时触发器显示当前工具名。
  • GitHub/隐私/条款离开主导航（桌面右侧图标 / 移动菜单 More 分组 / 页脚）。
  • 不改 URL：所有项仍是真实 <a href>，URL 结构/重定向/canonical 全不变（H9）。
D1
是否保留工具页现有 5-pill 工具导航？推荐：全部收进单层导航 + 在页脚保留 Tools 列（保住内链与可爬文本）。需确认是否先在工具页灰度、再推全站。
D2
是否改 URL / SEO？本方案不动 URL、不加重定向、不改 canonical/hreflang；只改导航 DOM 与顺序。若未来要合并工具页，必须 ADR + 全量重定向矩阵（H9）。
D3
5 语言同步导航结构在 root + es/ja/tw/zh 共 5 套手写副本，必须同批改（L-02）；nav 文案走既有 i18n 键，工具名保持 Square Image / Square Crop / Rounded Corners / Blurred Frame / Collage Maker。
D4
键盘与读屏模型Tools 下拉：Enter/Space 开、Esc 关、↑↓ 移动、关闭后焦点回触发器；移动菜单：aria-expanded/aria-controls、遮罩关闭、打开时焦点入面板（可参考 R0 语言菜单模型）。
实现落点：components.css 新增 .mc-nav*（或复用 .ghibli-nav 覆盖层）+ ui.js 注入移动菜单；95 页 HTML 的 nav 区同批替换。 门禁：token audit + check-layout（溢出/44px）+ functional 回归 + SEO harness（内链/canonical 不回归）。
