プライバシーポリシー

最終更新日：2025年1月13日

1. はじめに

MeCollageへようこそ。このプライバシーポリシーは、お客様が当社のウェブサイトを訪問し、当社のサービスを利用し、または当社と交流する際に、当社がどのようにお客様の情報を収集、使用、開示、および保護するかを説明するものです。このプライバシーポリシーを注意深くお読みください。このプライバシーポリシーの条件に同意しない場合は、サイトにアクセスしないでください。

2. 収集する情報

2.1 個人情報

当社は、お客様が当社のウェブサイトを訪問したり、アカウントを登録したり、当社のサービスを利用したりする際に、お客様が自発的に提供した個人情報を収集する場合があります。この情報には以下が含まれる場合があります：

  • 氏名および連絡先情報（提供を選択した場合）
  • メールアドレス（ニュースレターの購読やお問い合わせの場合）
  • ユーザー作成コンテンツ（コラージュ作成のためにアップロードした画像など）

2.2 非個人情報

また、お客様が当社のウェブサイトを訪問した際に、非個人情報を自動的に収集する場合があります。この情報には以下が含まれる場合があります：

  • IPアドレス
  • ブラウザの種類とバージョン
  • オペレーティングシステム
  • リファラーURL
  • 閲覧したページと当サイトでの滞在時間
  • デバイス情報

3. 情報の使用方法

収集した情報は、以下を含むさまざまな目的で使用されます：

  • サービスの提供、維持、および改善のため
  • お客様のリクエストを処理し完了するため
  • 当サイトでの体験をパーソナライズするため
  • お問い合わせへの回答を含む、お客様とのコミュニケーションのため
  • 利用パターンの分析および当サイトの改善のため
  • 技術的な問題の検出、防止、および対処のため
  • 法的義務の遵守のため

4. 情報の保存方法

当社は、不正アクセス、開示、改ざん、または破壊からお客様の情報を保護するために合理的な措置を講じています。ただし、インターネット上の送信方法や電子的な保存方法で100%安全なものはないことにご注意ください。

画像処理については、アップロードされたすべての画像はブラウザ内でローカルに処理され、明示的に別段の定めがない限り、当社のサーバーに保存されることはありません。

2.3 データの保持

お客様の画像を当社のサーバーに保存することはないため、ユーザーがアップロードしたコンテンツのデータ保持期間はありません。すべての画像処理はブラウザ内でローカルに行われます。セキュリティおよび分析目的で、サーバーログを最大30日間保持する場合があります。

5. 第三者との共有

当社は、お客様の個人情報を第三者の商業目的のために共有、販売、レンタル、または取引することはありません。ただし、以下の場合にお客様の情報を開示することがあります：

  • 法的要件を遵守するため、または適法なリクエストに対応するため
  • 当社、当社のユーザー、および公衆の権利、財産、または安全を保護するため
  • 当サイトの運営およびサービスの提供を支援するサービスプロバイダーと共有する場合

すべての画像処理はブラウザ内でローカルに行われ、ユーザー登録も不要なため、個人情報を収集または保存することはありません。そもそもユーザーデータを収集していないため、販売、レンタル、または取引を行うこともありません。

6. お客様の権利

お住まいの地域によっては、個人情報に関して以下のような特定の権利を有する場合があります：

  • 個人情報へのアクセス権
  • 不正確な情報の訂正を求める権利
  • 個人情報の削除を求める権利
  • 特定の情報の使用を拒否する権利

これらの権利を行使するには、当社の GitHub Issuesページ をご覧いただくか、 FAQページ をご確認ください。

7. クッキーおよび追跡技術

当社は、当サイトでの体験を向上させるために、クッキーおよび同様の追跡技術を使用する場合があります。クッキーは、ウェブサイトを訪問した際にお客様のデバイスに配置される小さなデータファイルです。ブラウザの設定でクッキーを制御できます。

8. プライバシーポリシーの変更

当社は、このプライバシーポリシーを随時更新することがあります。新しいプライバシーポリシーをこのページに掲載することで、変更をお知らせします。変更がないか定期的にこのプライバシーポリシーを確認することをお勧めします。

9. サポート

サポートについては、当社の GitHub Issuesページ を訪問して、バグの報告や機能のリクエストを行ってください。
