アスペクト比とは？

アスペクト比は画像の幅を高さで割った値で、16:9 や 4:5 のように 2 つの数字で表します。ピクセル数ではなく形を表す指標で、1920×1080 の写真、1280×720 の動画、3840×2160 のディスプレイはすべて 16:9 です。

アスペクト比は画像の大きさを示すものではありません。640×360 も 3840×2160 も 16:9 で、違うのは解像度だけです。サイズを変えるときは比率を保つと、顔や円、文字がゆがみません。

自分の画像のアスペクト比は？幅か高さを入力

既に分かっているピクセルサイズを計算機に入力すると、幅を高さで割って最も簡単な比率に直し、1:1・4:5・9:16・16:9・21:9 の中から最も近い比率を表示します。たとえば 1920×1080 は 16:9、1080×1350 は 4:5、1200×628 は 1.91:1 で最も近いのは 16:9 です。

片方しか分からないときは比率を選び、幅か高さを入力すると、もう片方がすぐに計算されます。9:16 で幅 1080 なら高さ 1920、4:5 で高さ 1350 なら幅 1080 です。どちら向きにも計算できます。

Instagram のアスペクト比とピクセルサイズ

Instagram のフィード画像は 1.91:1 から 4:5 の間に収める必要があります。正方形 1080×1080 は定番、縦長 1080×1350（4:5）はフィードで最もよく使われるサイズです。ストーリーズとリールは 1080×1920（9:16）、16:9 の横長画像はフィードで約 1080×608 で表示されます。1:1 に正確に切り抜くなら 正方形クロップ で拡大・移動して範囲を選べます。写真全体を残してぼかし背景を付けたいなら 正方形画像、複数枚で 9:16 のストーリーズを作るなら Instagram ストーリーコラージュ が便利です。

TikTok のサイズ：9:16 が基本

TikTok のプレーヤーは縦向きなので、ネイティブサイズは 1080×1920（9:16）です。1:1 は 200×200 のプロフィール画像のみ。4:5 や 16:9 の動画は切り抜かれるか黒帯が付きます。1080×1920 で構図を作り、上部と下部の UI に重ならないようテキストを安全領域に置きましょう。

YouTube のサイズ：16:9 の動画、9:16 の Shorts

YouTube の動画とサムネイルは 16:9 です。動画は 1920×1080、サムネイルは 1280×720。Shorts は 1080×1920（9:16）。チャンネルアバターやポッドキャストのカバーは 1:1 を使い、縦動画の一部はフィードで 4:5 のサムネイルが自動生成されます。

Web サイトの画像サイズ：メインビジュアル、カード、ウルトラワイド

Web サイトは自由ですが、16:9 のメインビジュアルは 1920×1080（軽量版は 1280×720）、4:5 のカードは 1080×1350、9:16 は 1080×1920 でモバイルのメインビジュアルやストーリー埋め込みに使えます。ウルトラワイドは 2560×1080 が定番です。

今すぐ使える無料の 16:9・9:16 サイズ

よく使う 16:9 は 1280×720、1920×1080、2560×1440、3840×2160。9:16 は 720×1280、1080×1920、2160×3840。計算機で比率を選び、分かっている辺を入力するだけで結果をコピーできます。アップロードも透かしも回数制限もありません。

画像を指定のアスペクト比に切り抜く・リサイズする方法

① 計算機で比率を決める（例：4:5 は 1080×1350）。② そのサイズに切り抜いて、顔や文字を伸ばさない。正方形クロップ は 1:1 に対応し、他の比率は任意のエディタで切り抜けます。③ 複数枚を並べるなら 正方形コラージュ、カード風に仕上げるなら 角丸ツール を使います。

コツは「先に切り抜き、あとでリサイズ」。順番を逆にすると処理済みのピクセルを捨ててしまい、切り抜かずに拡大縮小すると顔が伸びたように見えます。

21:9 の計算：厳密な比率とディスプレイ業界の表記

厳密な 21:9 は 2.333:1 で、高さ 1080 のときの幅は 2520×1080 です。市販の「21:9」ディスプレイの多くは実際には 64:27（2.370:1）で、2560×1080 が代表例。3440×1440 は 43:18（2.389:1）です。そのため本計算機は 2560×1080 を 21:9 の実用プリセットにし、この節で厳密値を説明しています。ソーシャルでは超ワイドはネイティブ非対応なので、投稿用に 16:9 か 9:16 も用意してください。

よくある質問

アスペクト比とは？

画像の幅を高さで割った値で、16:9 のように 2 つの数字で表します。1920×1080 は 1920 ÷ 1080 = 1.78、16 ÷ 9 = 1.78 なので 16:9 です。

画像のアスペクト比の計算方法は？

幅を高さで割ります。1080 ÷ 1350 = 0.8 で 4:5。比率を簡単にするには最大公約数で割ります。1920 と 1080 は 120 で割れて 16:9 です。

幅と高さしか分からないとき、アスペクト比は？

計算機に幅と高さを入力すると、幅÷高さを最も簡単な比率に直し（例：1920×1080 → 16:9）、1:1・4:5・9:16・16:9・21:9 のうち最も近い比率も表示します。

最も近い一般的な比率とは？

幅÷高さの値を 5 つの標準比率と比べ、最も近いものを表示します。たとえば 1200×628 は 1.91:1 で、最も近いのは 16:9 です。

16:9 のピクセルサイズは？

よく使う 16:9 は 1920×1080（Full HD）、1280×720（HD）、2560×1440（QHD）、3840×2160（4K）です。YouTube の動画・サムネイルや多くの Web サイトのメインビジュアルが 16:9 です。

Instagram の 4:5 のサイズは？

Instagram の縦長フィード投稿は 1080×1350 ピクセル（4:5）です。正方形より縦に広く使えます。

TikTok とリールの 9:16 は？

TikTok の動画、Instagram のリール・ストーリーズ、YouTube Shorts はすべて 1080×1920 ピクセル（9:16）です。

Instagram に 16:9 の画像を投稿できますか？

できますが、約 1080×608 の横長投稿として表示されます。フィード画像は 1.91:1〜4:5 の範囲内なので 16:9 も入りますが、4:5 のほうが画面を大きく使えます。

21:9 は何ピクセルですか？

厳密な 21:9 は 2.333:1 で、高さ 1080 なら幅 2520 ピクセルです。市販の「21:9」の多くは 64:27（2.370:1）で 2560×1080、3440×1440 は 43:18 です。計算機は 2560×1080 を実用プリセットとして使い、違いを説明しています。

このツールは画像をアップロードしますか？

いいえ。計算はブラウザ内だけで行い、アップロード・保存・送信は一切ありません。アカウントも不要です。

画像を特定の比率に切り抜くには？

正方形クロップツールで 1:1 に切り抜くか、ここで求めた比率とピクセルサイズで任意のエディタで切り抜きます。正方形の写真を並べるなら正方形コラージュが 1:1 を保ちます。
