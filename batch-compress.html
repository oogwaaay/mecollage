    Frequently asked questions

    How do I compress multiple images at once?

    Add several files, set a maximum width and optional target size in KB, press Compress, then download the ZIP.

    Can I set a maximum file size in KB?

    Yes. Enter a target in KB and the tool searches the best quality that still fits, for each image.

    Are my images uploaded to a server?

    No. Images are decoded, resized and re-encoded in your browser; the ZIP is built locally.

    What formats can I export?

    JPG or WebP. Transparent PNGs stay transparent when you choose WebP.

    Is there a limit on the number of images?

    No fixed limit, but very large batches are processed one by one in the browser. Start with 20–50 files for a smooth run.
