사진 합치기

사진을 가로·세로로 합치거나 바둑판으로 배치하세요.

여러 장의 사진을 한 장으로. 사진을 끌어다 놓고 가로, 세로, 바둑판 중에서 고르면 됩니다. 인스타그램 게시물, 카카오톡 공유, 스마트스토어 상품 이미지에 쓰기 좋고, 모든 처리는 브라우저에서 이루어져 사진이 업로드되지 않습니다.

사진 합치기 시작

가로로 합치기

높이가 자동으로 맞춰져 위아래가 반듯합니다.

세로로 합치기

너비를 맞춰 긴 스크린샷과 채팅을 한 장으로.

바둑판

2×2 네 장, 3×3 아홉 장, 열 수도 직접 조정.

자유 배치

사진을 원하는 위치에 두고 크기와 겹침도 조정.

사진 합치기 4단계

1. 사진 추가

캔버스에 끌어다 놓거나 Ctrl + V로 스크린샷을 붙여넣습니다.

2. 합칠 사진 선택

새로 추가한 사진은 자동 선택됩니다. Shift + 클릭이나 드래그로 여러 장을 고를 수 있습니다.

3. 배치 선택

가로, 세로, 바둑판 중에서 고르고 간격·테두리·모서리·배경을 조정합니다.

4. 저장 또는 복사

PNG, JPG, WebP로 내려받거나 복사해 카카오톡에 붙여넣습니다.

이런 때 쓰세요

인스타그램

1:1 게시물과 9:16 스토리 배치.

카카오톡 공유

대화 캡처를 세로로 이어 한 장으로.

스마트스토어

상품 사진 여러 장을 한 이미지로.

자주 묻는 질문

두 장의 사진을 한 장으로 만들려면?

사진 두 장을 캔버스에 추가하고 선택한 뒤 가로 또는 세로 배치를 고르면 됩니다. 미리보기에 최종 크기가 표시됩니다.

사진이 업로드되나요?

아니요. 사진은 브라우저 안에서 열리고 배치되고 저장됩니다. MeCollage 서버로 전송되지 않습니다.

한 번에 몇 장까지 합칠 수 있나요?

한 콜라주에 최대 20장입니다. 더 길게 만들려면 나눠서 합친 뒤 다시 합치세요.

어떤 형식으로 저장할 수 있나요?

PNG, JPG, WebP로 내보낼 수 있습니다.

무료인가요?

무료이며 회원가입과 워터마크가 없습니다.

이미지를 자르려면 이미지 분할, 용량을 줄이려면 이미지 일괄 압축. 한국어 도구 모음.

한국어 페이지는 파일럿이며 검색에는 노출되지 않습니다. 편집기 UI는 영어입니다.
